Implementasi Google Apps Script

Salin fungsi hash dan modul autentikasi login ini ke Apps Script Anda.

/**
 * Memunculkan Hash SHA-256 berbasis username dan password
 * @param {string} password - Password mentah pengguna
 * @param {string} username - Username / Email pengguna
 * @return {string} SHA-256 Hex Digest (64 Karakter)
 */
function hashPassword_(password, username) {
  var raw = username + ':' + (password || '');
  var digest = Utilities.computeDigest(Utilities.DigestAlgorithm.SHA_256, raw);
  return digest.map(function(b) {
    var v = (b < 0) ? b + 256 : b;
    return ('0' + v.toString(16)).slice(-2);
  }).join('');
}

/**
 * Contoh Fungsi Autentikasi Login untuk Google Sheets
 * @param {string} inputUsername - Input dari form login
 * @param {string} inputPassword - Input dari form login
 * @return {boolean} True jika cocok
 */
function validateLogin(inputUsername, inputPassword) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("Users");
  var data = sheet.getDataRange().getValues(); // Asumsi Kolom A: Username, Kolom B: Hashed Password
  
  var targetHash = hashPassword_(inputPassword, inputUsername);
  
  for (var i = 1; i < data.length; i++) {
    var storedUser = String(data[i][0]).trim();
    var storedHash = String(data[i][1]).trim();
    
    if (storedUser.toLowerCase() === inputUsername.trim().toLowerCase() && storedHash === targetHash) {
      return true; // Login Berhasil
    }
  }
  return false; // Login Gagal
}

Mengapa Menggunakan Username sebagai Salt?

Penggabungan username + ':' + password bertindak sebagai *Salt* bawaan. Ini mencegah dua pengguna dengan password yang sama (misal: "123456") memiliki string hash yang identik di database Google Sheets Anda, sehingga terlindung dari serangan *Rainbow Table*.

Catatan Keamanan Google Sheets

Pastikan sheet tempat Anda menyimpan hash tidak dapat diakses publik. Jalankan autentikasi melalui Web App Apps Script dengan mode Execute as me agar data kredensial tetap privat.
